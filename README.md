# Falcon
Amsat Pacsat Groundstation originally for FalconSat-3 and now for any implementation of the PACSAT protocols.

This was the result of a rainy Sunday and a touch of madness.  This is a Java implementation of a PacSat ground station.  it resulted in a full implementation of the Download and Upload protocols, or specifically reception of the PB packets and support for login and upload using the FTL0 protocol.

This also works with the C implementation of the PACSAT Server called pi_pacsat.
